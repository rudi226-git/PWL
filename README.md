Selamat datang di repositori resmi saya. Ruang ini didedikasikan untuk pengembangan materi perkuliahan, riset teknologi media digital, dan eksplorasi pemrograman modern menggunakan Framework Laravel.

---

## 🎓 Tentang Saya
Saya adalah dosen tetap di **STMIK IKMI Cirebon** dengan fokus riset pada media pembelajaran berbasis teknologi. Saya memiliki latar belakang pendidikan dari **STEI-ITB** (Magister Teknik) dengan spesialisasi Teknologi Media Digital dan Game.

* **📍 Domisili:** Cirebon, Jawa Barat.
* **🥋 Minat Lain:** Photography, Praktisi Olahraga Beladiri Tarung Derajat (Satlat Tanimulya).
* **🛠️ Kompetensi:** Asesor Kompetensi & Trainer Digital Talent Scholarship (Kominfo).

---

## 📚 Materi Perkuliahan (Teaching)
Repositori ini sering digunakan untuk mendistribusikan modul praktikum kepada mahasiswa. Beberapa topik utama meliputi:

* **Pemrograman Web Lanjut (PWL):** Fokus pada Laravel 12, RESTful API, dan Agentic AI.
* **UI/UX Design:** Penerapan User-Centered Design (UCD).
* **Augmented Reality (AR):** Pengembangan media edukasi interaktif.
* **Web Development:** PHP Native & Modern Frameworks.

---

## 🧪 Fokus Riset & Proyek
* **Augmented Reality for Education:** Transformasi modul ajar menjadi media interaktif.
* **AI-Assisted Development:** Implementasi LLM (DeepSeek/Gemini) dalam workflow pemrograman.
* **Agentic AI:** Eksplorasi pengembangan AI Agents untuk otomatisasi sistem web.
